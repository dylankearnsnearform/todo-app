- (version) Verified on web 2026-07-14: FastAPI latest 0.139.0 (Jul 2026); Python 3.12/3.13 safe target; FastAPI+Jinja2+HTMX+SQLite is current standard no-build full-stack pattern
- (decision) Paradigm = server-rendered hypermedia monolith (FastAPI+Jinja2+HTMX). Binds all UI interaction. Prevents split between a JSON SPA and server-rendered pages. Chosen over React/Vite SPA to honor PRD simplicity/maintainability bar (single language, no build, no client state)
- (decision) Single deployable: one FastAPI process serves HTML routes + mutations; no separate frontend server. Prevents divergent deployment topology
- (decision) Data ownership: SQLite is single source of truth for Todos; backend is sole writer; browser holds no authoritative state. Prevents two owners / client-side state drift
- (decision) State-mutation path: all mutations go through FastAPI route handlers -> DB write -> return updated HTML fragment. No DB access from templates, no client-side mutation store. Prevents inconsistent mutation paths
- (decision) Extensibility invariant: Todo persistence designed so a future owner/user relationship can be added without restructuring (no single-user assumption hard-coded into schema/queries). Serves PRD non-goal must-not-preclude-auth
- (decision) Error crossing: server returns proper HTTP status + rendered error fragment; client shows non-disruptive message and stays usable (FR-7). Prevents ad-hoc per-endpoint error handling
- (assumption) Persistence engine = SQLite via SQLAlchemy 2.0 (single-file durable store, survives restarts=FR-9, zero-config). Storage engine is seed, confirm in code
- (assumption) Deployment envelope (hobby): single uvicorn process, SQLite file on local disk; run locally or one small host. Production hardening deferred
- (assumption) Styling = plain CSS / minimal utility CSS for responsive layout (FR-6); no heavy CSS framework required
- (event) Fast-path draft: stack researched, ADs + conventions + seed drafted for distill
- (decision) AD-7 hypermedia fragment contract: list container has stable id #todo-list; each item fragment is a single root element id=todo-{id}; routes target these via consistent hx-target/hx-swap. Prevents create vs toggle vs delete routes returning fragments the client cannot swap consistently
